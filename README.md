# Alien Field Notes: The Two Day Earth Review

[![make.fun bounty](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/competitions/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000)

Entry for the make.fun bounty [Alien Field Notes: The Two Day Earth Review](https://make.fun/competitions/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000): one original line of plain text, at most 200 characters — a review of planet Earth left by an alien tourist.

## The line

> Once a year the locals celebrate by exploding the sky on purpose, then complain about the noise from their own party. 4/5 stars, would duck again.

## Run

```sh
python3 main.py   # writes the line to $MAKEFUN_OUTPUT_DIR/entry.txt (or /output/entry.txt)
```

`main.py` uses only the Python standard library.
